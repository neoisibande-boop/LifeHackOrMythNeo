# Native Android design
- XML layouts, platform Material theme; no web view or Expo.
- Navy #122B3F, teal #006B65, off-white #F5F8F8; red for incorrect answers.
- System sans-serif with medium-weight headings, 24dp gutters, 56dp minimum button height.
- Scrollable screens, readable statements, immediate text feedback (not color alone).
- Four screens: welcome, quiz, score, review. Safe-area padding follows window insets.
