Describe what “Life Hack or Urban Myth?” does and how it helps users distinguish useful tips from misinformation. Explain how the flashcard quiz, feedback, and explanations support learning and safer decisions.

3. Describe the design considerations
•	Welcome screen: app description, instructions, and a Start button.
•	Quiz screen: a statement, Hack (True) and Myth (False) buttons, answer feedback, and Next.
•	Score screen: the total number of correct answers and personalised feedback.
•	Review screen: all statements, correct answers, explanations, and the user’s choices.

Explain your navy-and-teal colour scheme, readable text, scrollable layouts, and why Next remains disabled until an answer is selected. Describe the design you actually use if you personalise these choices.

5. Explain the application logic
•	How the app moves through the questions and checks each answer.
•	How it calculates the score and prevents repeated taps from increasing it.
•	How Play again resets the quiz and how progress is preserved during rotation.

Mention the roles of MainActivity.kt (screens and navigation), QuizEngine.kt (quiz logic and scoring), and QuestionBank.kt (statements, correct answers, explanations, and sources).
